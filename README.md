# Mayuravel Pakkiyarajah — Portfolio

A minimal, responsive, one-page Angular portfolio for a Full-Stack Developer.

## Stack

- Angular
- TypeScript
- SCSS

## Run locally

```bash
npm install
npm start
```

Then open:

http://localhost:4200

## Build

```bash
npm run build
```

## Personalize

All portfolio content is centralized in:

`src/app/data/portfolio.data.ts`

Update:

- name
- email
- GitHub URL
- LinkedIn URL
- project GitHub URLs
- project live URLs
- experience
- education
- skills
- project descriptions
- resume

## Deployment

The generated Angular build is static and can be deployed to Vercel, Netlify, GitHub Pages, or any static hosting provider.
